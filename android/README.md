# Health  

Main Objective

- Scaleable  

      - Can be extended to support multiple devices.
      - Currently supported devices include MiBand2

- Always On  

      - Provide interface to monitor smart band/gadget/watch data 24/7 
      - whether device is sleep, app is in foreground, background.

- Integrations and Bindings  

      - Can be intergrated in any android app as 3rd party dependency with Slim API
      - React Native bindings with native module bridging and js wrapper module API
      - Flutter bindings

- Data Logging Support  

      - Log sensor data to sqlite and provide reactive API to clients for fetching.
      - Log sensor data to remote data store for the sake of demo
 
- Sample Application POC:  

      - Native android App Sample
      - React App for POC and testing always on concept.
      - React Native App to test and demo RN bindings
      - Flutter App to test and demo RN bindings
